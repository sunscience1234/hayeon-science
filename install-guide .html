📱 내 폰에 맞는 방법 선택
⚠️ 반드시 사파리(Safari)로 열어야 해요!
카카오톡에서 링크를 누르면 카카오 브라우저로 열려요. 아래 방법으로 사파리로 다시 열어주세요!
1
앱 주소를 사파리로 열기
카카오톡에서 링크를 꾹 누르기 → "Safari로 열기" 선택

또는 아이폰 사파리 🧭 앱에서 직접 아래 주소 입력:
🔗 sunscience1234.github.io/hayeon-science/
2
화면 아래 "···" 버튼 클릭
사파리에서 앱이 열리면 화면 맨 아래 오른쪽에 있는 "···" (점 세 개) 버튼을 눌러요.
← 🖥 sunscience1234.github.io 🔄 ···
3
"공유" 클릭 📤
메뉴가 나오면 맨 위 "공유" 를 눌러요.
(화살표가 위로 올라가는 아이콘 📤)
4
아래로 스크롤 → "홈 화면에 추가 ⊕"
공유 화면에서 아래로 스크롤하면 "홈 화면에 추가 ⊕" 가 나와요. 클릭!
📋 북마크 추가 → 즐겨찾기에 추가 → 빠른 메모에 추가 → 페이지에서 찾기 → 홈 화면에 추가 ⊕
5
오른쪽 위 "추가" 클릭
앱 이름 확인 후 오른쪽 위 "추가" 버튼을 누르면 완료!
🎉
홈 화면에 하연통합과학 아이콘이 생겼어요!
이제 앱처럼 바로 열 수 있어요 😊
💡 크롬(Chrome) 브라우저를 사용하세요!
카카오톡 링크를 누르면 카카오 브라우저로 열려요. 크롬으로 다시 열어주세요.
1
크롬으로 링크 열기
카카오톡에서 링크 누른 후 → 오른쪽 위 점 세 개 ⋮ → "Chrome으로 열기" 선택
2
크롬 메뉴 열기
크롬에서 앱이 열리면 오른쪽 위 점 세 개 ⋮ 버튼을 눌러요.
3
"앱 설치" 또는 "홈 화면에 추가"
메뉴에서 "앱 설치" 또는 "홈 화면에 추가" 를 눌러요.
4
"설치" 클릭
팝업에서 "설치" 버튼을 누르면 완료!
🎉
홈 화면에 하연통합과학 아이콘이 생겼어요!
이제 앱처럼 바로 열 수 있어요 😊

✅ 허용하면 선생님 답변이 오면 자동으로 알림이 와요
