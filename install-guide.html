📱 내 폰에 맞는 방법 선택
⚠️ 반드시 사파리(Safari)로 열어야 해요!
카카오톡에서 링크를 누르면 카카오 브라우저가 열려요. 사파리로 다시 열어야 설치가 돼요.

1
💬
카카오톡에서 링크 꾹 누르기
링크를 짧게 누르지 말고 길게 꾹 눌러주세요. 메뉴가 나와요.
2
🧭
"Safari로 열기" 선택
나온 메뉴에서 "Safari로 열기" 를 선택해요.
3
📤
하단 공유 버튼 클릭
사파리 화면 아래쪽 가운데에 있는 네모에 화살표 올라가는 버튼을 눌러요.
4
➕
"홈 화면에 추가" 선택
아래로 스크롤하면 "홈 화면에 추가" 메뉴가 나와요.
5
✅
오른쪽 위 "추가" 클릭
이름 확인 후 오른쪽 위 "추가" 버튼을 누르면 완료!
🎉
홈 화면에 하연통합과학 아이콘이 생겼어요!
이제 앱처럼 바로 열 수 있어요 😊
💡 크롬(Chrome) 브라우저를 사용하세요!
삼성 인터넷이나 다른 브라우저도 되지만 크롬이 가장 잘 돼요.

1
💬
카카오톡에서 링크 클릭
링크를 눌러서 앱이 열리면 오른쪽 위 점 세 개 ⋮ 메뉴를 눌러요.
2
🌐
"Chrome으로 열기" 선택
메뉴에서 "다른 브라우저로 열기" 또는 "Chrome으로 열기" 선택해요.
3
⋮
크롬 메뉴 열기
크롬에서 앱이 열리면 오른쪽 위 점 세 개 ⋮ 버튼을 눌러요.
4
📲
"앱 설치" 또는 "홈 화면에 추가"
메뉴에서 "앱 설치" 또는 "홈 화면에 추가" 를 눌러요.
5
✅
"설치" 또는 "추가" 클릭
팝업에서 "설치" 또는 "추가" 버튼을 누르면 완료!
🎉
홈 화면에 하연통합과학 아이콘이 생겼어요!
이제 앱처럼 바로 열 수 있어요 😊

✅ 허용 안 하면 직접 앱에 들어가서 확인해야 해요
